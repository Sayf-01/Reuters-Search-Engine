# Reuters-Search-Engine
A search engine built from scratch over 21,000+ Reuters news articles using inverted indexing, boolean query search, and dictionary compression.

## Data set 
I am using "Reuters-21578, Distribution 1.0" i found this source from "https://archive.ics.uci.edu/dataset/137/reuters+21578+text+categorization+collection", 
it is also available from David D. Lewis' professional home page, currently: "http://www.research.att.com/~lewis"
